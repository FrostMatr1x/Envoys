# Визуальный редактор сценариев — Справочник действий

Это справочник по всем типам узлов, которые может создавать Визуальный редактор сценариев. В каждом разделе описано назначение узла, его редактируемые поля и то, какой экран настроек за них отвечает.

Все линейные узлы имеют общее поле **Next** (подписано как «Далее») — ID следующего узла в цепочке; пустое Next завершает цепочку. Узлы ветвления вместо этого распределяют выполнение по одной или нескольким **ветвям**, каждая из которых определяется ID головного узла.

---

## `start`

**Точка входа цепочки.**

- Назначение: точка входа цепочки события. Выполнение всегда начинается здесь, когда событие срабатывает.
- Поля: ID **Next**.
- Не может быть удалён.

---

## `say` — Сообщение

Отправляет сообщение в чат.

- Поля:
  - **Текст сообщения**.
  - Флаг **Global** (отправляется ли сообщение глобально, а не игроку события).
  - ID **Next**.

---

## `wait` — Ожидание

Приостанавливает цепочку на заданную длительность.

- Поля:
  - Значение **длительности**.
  - **Единица**: тики / секунды / минуты / часы.
  - ID **Next**.

---

## `move` — Движение

Перемещает NPC в целевую позицию.

- Поля:
  - **Target X / Y / Z**.
  - ID **Next**.

---

## `command` — Команда

Выполняет одну или несколько серверных команд.

- Поля:
  - **Список серверных команд**, добавляемых по одной.
  - ID **Next**.

---

## `lookAt` — Повернуть к цели

Заставляет NPC посмотреть на цель.

- Поля:
  - **Режим цели**:
    - **"event player"** — смотрит на игрока, вызвавшего событие; координаты не используются.
    - **"coordinates"** — использует явные **X / Y / Z**.
  - ID **Next**.

---

## `trade` — Трейд

Открывает торговое предложение игроку.

- Поля:
  - **Список предложений**. Каждое предложение содержит:
    - **Input 1** (предмет, с необязательным **count**).
    - Необязательный **Input 2** (предмет, с необязательным **count**).
    - **Output** (предмет, с необязательным **count**).
    - **`priceMultiplier`**.
    - **`demand`**.
    - **`maxTrades`**.
    - **`resetTime`** (в секундах).
    - Необязательный **`requiredLevel`**.
  - ID **Next**.

---

## Узлы ветвления

У узлов ветвления нет единственного указателя Next. Вместо этого они выбирают одну из нескольких **ветвей**, каждая из которых указывает на ID головного узла.

### `dialogue_choice` — Диалог

Показывает фразу NPC с вариантами ответа.

- Поля:
  - **Текст фразы NPC**.
  - **Варианты ответа** — у каждого варианта есть **key** и **branch** (ID головного узла для перехода).
- **key** выбранного варианта возвращается в скрипт, поэтому продолжение может реагировать на то, какой ответ выбрал игрок.

### `random_choice` — Рандомайзер

Случайно выбирает одну из **N** ветвей.

- Поля: **N ветвей**, выбираемых через `math.random(N)`.

### `quest_check` — Проверка квеста

Ветвится в зависимости от состояния завершения квеста.

- Поля:
  - **Quest id**.
  - Ровно **две ветви**: **completed** и **not completed**.

---

## Действия с квестами

### `quest_start` — Выдать квест

- Поля: **Quest id**, ID **Next**.

### `quest_advance` — Продвинуть этап

- Поля: **Quest id**, **amount**, ID **Next**.

### `quest_complete` — Отметить выполненным

- Поля: **Quest id**, ID **Next**.

---

## `savepoint` — Точка сохранения

Сохраняет чекпоинт для конкретного игрока, к которому позже может вернуть `loadpoint`.

- Поля:
  - **Key** — допускаются только символы `[a-zA-Z0-9_]`.
  - **Internal UUID** — генерируется автоматически, только для чтения.
  - Переключатель **"Abort after save"**.
  - ID **Next**.

Когда цепочка достигает точки сохранения, она сохраняет чекпоинт для игрока. В зависимости от переключателя прерывания цепочка либо продолжается, либо прерывается. В любом случае сохранённое продолжение достижимо из соответствующего `loadpoint`.

---

## `loadpoint` — Загрузить точку

Возвращает игрока к ранее сохранённому чекпоинту.

- Поля:
  - **Key** — ключ точки сохранения, к которой нужно вернуться.
  - ID **Next** — используется как **запасной вариант**, когда у игрока ещё нет чекпоинта.

---

## Ветви, варианты и валидация

Внутри **редактора ветвей** вы редактируете ветви варианта — то есть **ID головных узлов**, на которые переходит каждый вариант. **text** варианта — это то, что видит игрок; **key** варианта — это то, что получает скрипт при его выборе. Согласовывайте оба значения с тем, как ваша логика продолжения читает возвращённый ключ.

Правила валидации, проверяемые во время компиляции:

- **ID узлов должны быть уникальными**.
- Каждое значение **Next** должно ссылаться на **допустимый ID узла**.
- Головные узлы ветвей должны ссылаться на допустимые ID узлов.

При нарушении любого из этих правил **компиляция сообщает об ошибке** вместо создания Lua.
