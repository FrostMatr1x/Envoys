# События

NPC управляется событиями. У каждого NPC выполняется **один** скрипт, `main.lua`, регистрируемый
из сохранения мира по пути `world/envoys/lua/<npc_uuid>/main.lua`. Внутри этого скрипта вы
подписываетесь на события через глобальную таблицу `envoys`:

```lua
envoys.on(event, fn[, arg])
```

Существует четыре типа событий: `click`, `update`, `range` и `kick`.

**На каждое событие существует только один обработчик.** Повторный вызов `envoys.on` с тем же
именем события *заменяет* ранее зарегистрированный обработчик; подписки не накапливаются (Важно: при ошибке валидации новый метод не удаляет старый, а перекрывает старый, сохраняя прошлый код).

Действия (`wait`, `move`, `dialogue`, `trade`, `waitEvent`) могут приостанавливать корутину события.
Пока она приостановлена, NPC продолжает обрабатывать другие события; скрипт возобновляется с того
места, где остановился.

## click

**Назначение:** реагировать на взаимодействие игрока с NPC (ПКМ, `mobInteract`).

**Контекст игрока:** взаимодействующий игрок.

**Параметры:** отсутствуют.

```lua
envoys.on("click", function(player)
    player:sendMessage("Hello!")
end)
```

## update

**Назначение:** периодический тик NPC — блуждание, атмосферная логика, внутренние
изменения состояния.

**Контекст игрока:** **отсутствует.** `player` равен `nil`; `update` выполняется без привязанного
игрока.

**Параметры:** интервал в тиках. Он **необязателен** и по умолчанию равен
**1 тику**, если опущен.

```lua
envoys.on("update", function(player)
    -- player - nil здесь
end, INTERVAL_TICKS)
```

**Ограничение:** действия, требующие игрока, **запрещены** в `update`:
`dialogue`, `trade`, `lookAt`, действия квестов, а также `savepoint`/`loadpoint`. Используйте `click`
или `range`, когда игрок должен присутствовать.

## range

**Назначение:** реагировать на вход игрока в радиус NPC.

**Контекст игрока:** игрок, вошедший в радиус.

**Параметры:** радиус в блоках.

```lua
envoys.on("range", function(player)
    player:sendMessage("Подними эту банку. А теперь брось в урну.")
end, RADIUS_BLOCKS)
```

Событие срабатывает при пересечении границы радиуса (при входе), а не непрерывно, пока игрок
остаётся внутри.

## kick

**Назначение:** реагировать на получение NPC урона.

**Контекст игрока:** атакующий игрок, который **может быть `nil`** (например, урон от окружения
или не от игрока).

**Параметры:** отсутствуют.

```lua
envoys.on("kick", function(player)
    if player then
        envoys.say("Остановись. С гибелью этого персонажа нить вашей судьбы будет оборвана.")
    end
end)
```
