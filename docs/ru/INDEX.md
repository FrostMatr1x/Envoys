# Envoys — Документация

Envoys — это мод для NeoForge 1.21.1, добавляющий полностью настраиваемых NPC. Каждому NPC можно
задать паспорт (имя, размер, скорость, здоровье, флаги видимости и поведения), собственную текстуру скина, 
трейды и квесты. Помимо этого, Envoys включает движок Lua-скриптов и визуальный
редактор графов, так что логику NPC можно писать либо кодом (`main.lua`), либо в виде графа узлов,
который компилируется в тот же Lua.

Возможности мода:

- Паспорта NPC, скины, трейды и квесты, хранящиеся в сохранении мира.
- Изолированный движок Lua со скриптом на каждого NPC и событийно-ориентированным API.
- Действия, приостанавливающие скрипт (`wait`, `move`, `dialogue`, `trade`, `waitEvent`).
- Визуальный редактор, компилирующий графы в Lua и декомпилирующий Lua обратно в графы.
- Загрузка и выгрузка скриптов NPC для сервера.
- Предметы **«Настройщик NPC»** и **«Яйцо призыва NPC»** во вкладке **«Envoys»**; сущность называется **«NPC»**.

## Как читать эту недо-документацию

**Раздел 1 обязателен для понимания логики мода; Разделы 2 и 3 можно изучать по выбору или в
любом порядке.** События, команды и квесты задают контракт, на который опирается каждый скрипт
и каждый оператор; Lua API и визуальный редактор построены поверх этого контракта.

## Концепция

Конфигурация NPC хранится в сохранении мира, поэтому мир несёт своих NPC с собой, без лишних
файлов для копирования. Lua-скрипты лежат по пути `world/envoys/lua/<npc_uuid>/main.lua` — ровно
один скрипт на каждого NPC. Визуальный редактор компилирует графы в Lua и декомпилирует Lua обратно
в графы, поэтому оба способа создания правят один и тот же источник истины.
