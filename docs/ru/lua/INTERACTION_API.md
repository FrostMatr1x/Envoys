# API взаимодействия

API Lua-скриптов доступен скриптам как глобальная таблица `envoys`. Скрипт
располагается по пути `world/envoys/lua/<npc_uuid>/main.lua` и выполняется при
срабатывании события для этого NPC.

## Глобальный контекст

- Таблица API всегда доступна как `envoys`; импорт не требуется.
- Необязательный аргумент `player` означает **целевого игрока текущего события**,
  если он опущен. Если передать игрока явно, действие нацелено на него.
- **Приостанавливающие функции** (`wait`, `move`, `waitEvent`, `dialogue`, `trade`)
  останавливают корутину события и возвращают управление при её возобновлении. Их
  **нельзя** вызывать внутри вложенных `coroutine.create` / `coroutine.wrap`.
- Лимит инструкций на одно возобновление задаётся ключом конфигурации
  `lua.instructionLimit` (по умолчанию `50000`). Занятый цикл приводит к ошибке
  `too long without yielding`.
- `envoys.command` управляется ключом конфигурации `lua.allowCommands` (по умолчанию `true`)
  и выполняется с **уровнем прав 4**.

## Функции

### `envoys.dialogue(message, answers [, player])`

Показать экран диалога NPC и ждать выбора. **Приостанавливает.**

- **Параметры**
  - `message` *(string)* — реплика NPC для отображения.
  - `answers` *(table)* — карта вида `{ ["Текст ответа"] = "choice_key", ... }`.
    Каждая запись требует непустой отображаемый текст и непустой ключ.
  - `player` *(player proxy, необязательно)* — по умолчанию целевой игрок текущего события.
- **Возвращает** — выбранный `choice_key` *(string)* или `nil`, если диалог был закрыт
  без выбора.
- **Примечания** — экран показывает несколько вариантов. `answers` не должен быть пустым.

```lua
local choice = envoys.dialogue("Курьер? Я ждал эту доставку. Фишка у тебя?", {
    ["Вот платиновая фишка."] = "chip",
    ["Правда в том, что игра была подстроена с самого начала."] = "rigged",
})

if choice == "chip" then
    envoys.say("Отличная работа. Твой гонорар.")
else
    envoys.say("Постой, что ты имеешь в виду?..")
end
```

### `envoys.trade(offers [, player])`

Открыть интерфейс торговли и ждать его закрытия. **Приостанавливает.**

- **Параметры**
  - `offers` *(array of tables)* — предложения для отображения. Каждое предложение поддерживает:
    - `in1` *(string)* — id первого входного предмета. **Обязательно.**
    - `in1count` *(number, необязательно)* — по умолчанию `1`.
    - `in2` *(string, необязательно)* — id второго входного предмета.
    - `in2count` *(number, необязательно)* — по умолчанию `1`.
    - `out` *(string)* — id выходного предмета. **Обязательно.**
    - `outcount` *(number, необязательно)* — по умолчанию `1`.
    - `priceMultiplier` *(number, необязательно)* — по умолчанию `1.0`, ограничено диапазоном `0.1..10`.
    - `demand` *(number, необязательно)* — по умолчанию `0`.
    - `maxTrades` *(number, необязательно)* — по умолчанию `-1` (без ограничений).
    - `resetTime` *(number, необязательно)* — секунды до пополнения запаса; по умолчанию `-1` (никогда).
    - `requiredLevel` *(number, необязательно)* — скрывает предложение, пока
      `envoys.merchant.getUnlocked()` не станет `>= requiredLevel`.
  - `player` *(player proxy, необязательно)* — по умолчанию целевой игрок текущего события.
- **Возвращает** — ничего; возобновляется, когда интерфейс закрыт.
- **Примечания** — неизвестные id предметов вызывают ошибку. Если общая цена предложения превышает
  **64 предмета**, излишек автоматически переносится во второй слот оплаты (`in2`), при условии что `in2` пуст
  или содержит тот же самый предмет.

```lua
envoys.trade({
    {
        in1 = "minecraft:emerald",
        in1count = 3,
        out = "minecraft:bread",
        outcount = 1,
        maxTrades = 12,
    },
    {
        in1 = "minecraft:emerald",
        in1count = 1,
        out = "minecraft:arrow",
        outcount = 16,
        priceMultiplier = 1.25,
    },
})
```

### `envoys.waitEvent(name [, timeoutTicks])`

Ждать события по имени. **Приостанавливает.**

- **Параметры**
  - `name` *(string)* — одно из `"click"`, `"kick"`, `"range"`, `"update"`.
  - `timeoutTicks` *(number, необязательно)* — максимальное время ожидания в тиках.
- **Возвращает** — player proxy для событий игрока или `nil` при тайм-ауте.

```lua
local player = envoys.waitEvent("click", 600)
if player == nil then
    -- Срабатывает при истечении 30 секунд
    envoys.say("...Но никто не пришёл.")
end
```

## Точки сохранения

Точки сохранения хранят строку для каждой пары `(NPC, player)` и сохраняются между выходом
из игры и перезапуском сервера.

### `envoys.checkpoint.get(key [, player])`

- **Параметры**
  - `key` *(string)* — должен соответствовать `[a-zA-Z0-9_]{1,64}`.
  - `player` *(player proxy, необязательно)* — по умолчанию целевой игрок текущего события.
- **Возвращает** — сохранённую строку или `nil`, если значение не задано.

### `envoys.checkpoint.set(key, value [, player])`

- **Параметры**
  - `key` *(string)* — должен соответствовать `[a-zA-Z0-9_]{1,64}`.
  - `value` *(string)* — должен содержать 1..256 символов.
  - `player` *(player proxy, необязательно)* — по умолчанию целевой игрок текущего события.
- **Возвращает** — ничего.

```lua
envoys.checkpoint.set("ruins_gate", "visited")

if envoys.checkpoint.get("ruins_gate") == "visited" then
    envoys.say("Мысль о том, что скрипт скомпилировался без ошибок, наполняет вас решимостью.")
else
    envoys.say("Впереди неизвестность...")
end
```

## Торговец

### `envoys.merchant.getUnlocked([player])`

- **Параметры**
  - `player` *(player proxy, необязательно)* — по умолчанию целевой игрок текущего события.
- **Возвращает** — количество разблокированных слотов торговли *(int)*.

### `envoys.merchant.addUnlocked([amount [, player]])`

Разблокировать дополнительные слоты торговли для этого NPC.

- **Параметры**
  - `amount` *(number, необязательно)* — количество добавляемых слотов; по умолчанию `1`, должно быть `> 0`.
  - `player` *(player proxy, необязательно)* — по умолчанию целевой игрок текущего события.
- **Возвращает** — ничего.

```lua
envoys.merchant.addUnlocked(1)
envoys.say("New wares unlocked (" .. envoys.merchant.getUnlocked() .. " slots).")
```
