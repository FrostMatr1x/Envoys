# Основные действия

API Lua-скриптов доступен скриптам как глобальная таблица `envoys`. Скрипт
располагается по пути `world/envoys/lua/<npc_uuid>/main.lua` и выполняется при
срабатывании события для этого NPC.

## Глобальный контекст

- Таблица API всегда доступна как `envoys`; импорт не требуется.
- Необязательный аргумент `player` означает **целевого игрока текущего события**,
  если он опущен. Если передать игрока явно, действие нацелено на него.
- **Приостанавливающие функции** (`wait`, `move`, `waitEvent`, `dialogue`, `trade`)
  останавливают корутину события и возвращают управление при её возобновлении. Их
  **нельзя** вызывать внутри вложенных `coroutine.create` / `coroutine.wrap`.
- Лимит инструкций на одно возобновление задаётся ключом конфигурации
  `lua.instructionLimit` (по умолчанию `50000`). Занятый цикл приводит к ошибке
  `too long without yielding`.
- `envoys.command` управляется ключом конфигурации `lua.allowCommands` (по умолчанию `true`)
  и выполняется с **уровнем прав 4**.

## Функции

### `envoys.say(message [, player])`

Отправить сообщение в чат целевому игроку события.

- **Параметры**
  - `message` *(string)* — текст для отправки.
  - `player` *(player proxy, необязательно)* — получатель; по умолчанию целевой игрок
    текущего события.
- **Возвращает** — ничего.
- **Примечания** — сообщение отправляется только если игрок в сети.

```lua
envoys.say("Welcome, traveler.")
```

### `envoys.command(command)`

Выполнить серверную команду от имени NPC.

- **Параметры**
  - `command` *(string)* — команда для выполнения. Ведущий `/` необязателен.
- **Возвращает** — ничего.
- **Примечания** — требует конфигурацию `lua.allowCommands` (по умолчанию `true`). Выполняется
  с **уровнем прав 4** и подавляет вывод команды. Выбрасывает ошибку, если команды
  отключены.

```lua
envoys.command("time set day")
```

### `envoys.lookAt(target)`

Повернуть NPC к player proxy или позиции.

- **Параметры**
  - `target` *(player proxy | `{x=,y=,z=}`)* — точка, на которую нужно смотреть.
- **Возвращает** — ничего.
- **Примечания** — для player proxy текущая позиция игрока определяется в момент
  вызова.

```lua
envoys.lookAt({ x = 10, y = 64, z = -20 })
```

### `envoys.move(x, y, z [, speed])`

Провести NPC по пути к позиции. **Приостанавливает.**

- **Параметры**
  - `x`, `y`, `z` *(numbers)* — координаты назначения.
  - `speed` *(number, необязательно)* — модификатор скорости передвижения.
- **Возвращает** — `true` по прибытии, `false` если путь не найден или движение
  отменено.
- **Примечания** — приостанавливает корутину события до прибытия NPC или окончания движения.

```lua
local arrived = envoys.move(120, 65, 30, 1.0)
if not arrived then
    envoys.say("I cannot reach you.")
end
```

### `envoys.teleport(x, y, z [, yaw, pitch])`

Мгновенно телепортировать NPC. **Не приостанавливает.**

- **Параметры**
  - `x`, `y`, `z` *(numbers)* — координаты назначения.
  - `yaw` *(number, необязательно)* — по умолчанию текущий yaw NPC.
  - `pitch` *(number, необязательно)* — по умолчанию `0`.
- **Возвращает** — ничего.
- **Примечания** — останавливает любое активное перемещение по пути.

```lua
envoys.teleport(120, 65, 30)
```

### `envoys.wait(ticks)`

Приостановить выполнение на N тиков. **Приостанавливает.**

- **Параметры**
  - `ticks` *(number)* — количество игровых тиков (20 тиков = 1 секунда).
- **Возвращает** — ничего.

```lua
envoys.say("Маг никогда не опаздывает...")
envoys.wait(60) -- Пауза в 3 секунды (60 тиков)
envoys.say("...он приходит точно тогда, когда считает нужным.")
```

### `envoys.sound(soundId [, volume, pitch])`

Воспроизвести звук у NPC.

- **Параметры**
  - `soundId` *(string)* — id звукового события, например `"minecraft:entity.villager.yes"`.
  - `volume` *(number, необязательно)* — по умолчанию `1.0`.
  - `pitch` *(number, необязательно)* — по умолчанию `1.0`.
- **Возвращает** — ничего.
- **Примечания** — неизвестный id звука вызывает ошибку.

```lua
envoys.sound("minecraft:entity.villager.yes", 1.0, 1.0)
```

### `envoys.particle(particleId, count [, speed, dx, dy, dz])`

Создать частицы у NPC.

- **Параметры**
  - `particleId` *(string)* — id типа частиц.
  - `count` *(number)* — количество частиц.
  - `speed` *(number, необязательно)* — скорость частиц.
  - `dx`, `dy`, `dz` *(numbers, необязательно)* — разброс смещения.
- **Возвращает** — ничего.

```lua
envoys.particle("minecraft:happy_villager", 10, 0.1, 0.5, 0.5, 0.5)
```

### `envoys.effect(effectId, durationTicks [, amplifier, showParticles])`

Наложить эффект моба на NPC.

- **Параметры**
  - `effectId` *(string)* — id эффекта, например `"minecraft:speed"`.
  - `durationTicks` *(number)* — длительность эффекта в тиках.
  - `amplifier` *(number, необязательно)* — усилитель эффекта (0 = уровень I).
  - `showParticles` *(boolean, необязательно)* — показывать ли частицы.
- **Возвращает** — ничего.

```lua
envoys.effect("minecraft:speed", 200, 1, false)
```

### `envoys.pos()`

Получить текущую позицию NPC.

- **Параметры** — нет.
- **Возвращает** — таблицу `{x=,y=,z=}`.

```lua
local p = envoys.pos()
envoys.say("I am at " .. p.x .. ", " .. p.y .. ", " .. p.z)
```

### `envoys.name()`

Получить отображаемое имя NPC.

- **Параметры** — нет.
- **Возвращает** — отображаемое имя NPC *(string)*.

```lua
envoys.say("My name is " .. envoys.name())
```

### `envoys.playersInRange(radius)`

Найти игроков рядом с NPC.

- **Параметры**
  - `radius` *(number)* — радиус поиска в блоках.
- **Возвращает** — массив player proxy в пределах радиуса.

```lua
for _, p in ipairs(envoys.playersInRange(16)) do
    p:sendMessage("Hello, " .. p.name)
end
```

### `envoys.on(event, function(player) ... end [, arg])`

Зарегистрировать callback события для этого скрипта.

- **Параметры**
  - `event` *(string)* — имя события (см. документацию по событиям).
  - `function(player)` *(function)* — callback, вызываемый при срабатывании события; `player`
    — player proxy, связанный с событием.
  - `arg` *(number, необязательно)* — аргумент, зависящий от события: для `update` это
    интервал в тиках; для `range` это радиус в блоках.
- **Возвращает** — ничего.
- **Примечания** — callback выполняется как новая корутина события, поэтому он может
  использовать приостанавливающие функции.

```lua
envoys.on("update", function(player)
    player:sendMessage("Still here?")
end, 200)
```

## Player Proxy

Player proxy возвращается callback-ами событий, `envoys.playersInRange` и подобными
API. Это лёгкий дескриптор, а не снимок состояния.

**Поля**

| Поле   | Тип             | Описание                            |
|--------|-----------------|-------------------------------------|
| `name` | string          | Отображаемое имя игрока.            |
| `uuid` | string          | UUID игрока.                        |
| `pos`  | `{x=,y=,z=}`    | Текущая позиция игрока.             |

**Методы**

- `sendMessage(msg)` — отправить сообщение в чат этому игроку.
- `distanceTo(target)` — расстояние в блоках до `target`, где `target` — это player
  proxy или таблица `{x=,y=,z=}`.

**Примечания** — доступ к полям и методам каждый раз определяет игрока в сети. Если игрок
не в сети, доступ к proxy вызывает ошибку.

```lua
envoys.on("click", function(player)
    if player:distanceTo({ x = 0, y = 64, z = 0 }) < 10 then
        player:sendMessage("You are close to the origin.")
    end
end)
```
